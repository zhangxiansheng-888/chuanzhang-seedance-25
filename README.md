# 船长AI视界 · Seedance 2.5 OS

船长AI视界出品的 Seedance 2.5 视频创作技能。把普通创意整理为即梦/Dreamina 可直接使用的视频工作流和提示词。

## 能做什么

- 4–30 秒短视频与时间轴脚本
- 30–180 秒长视频故事规划
- 图片、视频、音频多模态参考分工
- 原生续写与无缝转场
- 局部编辑、BGM 移除与视角修改
- 绿幕合成、白模渲染和多格分镜
- 修复变脸、换装、穿模、参考串用与剧情漂移

## 安装

将 `skill/seedance-25` 完整复制到个人 Codex 技能目录：

```text
~/.codex/skills/seedance-25
```

重新打开一个 Codex 任务后使用：

```text
使用 $seedance-25，把我的创意整理成一个30秒竖屏视频提示词。
```
