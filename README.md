# 船长AI视界 · Seedance 2.5 OS

把一句普通创意，整理成即梦/Dreamina Seedance 2.5 可直接使用的视频方案和完整提示词。适合不会写专业提示词的新手，也适合需要提高稳定性、修改成片的创作者。

## 这个技能能做什么？

| 创作需求 | 技能会帮你完成 |
|---|---|
| 4–30秒短视频 | 确定画幅、时长、镜头、动作、情绪、对白和音效，并输出时间轴提示词 |
| 30–180秒长故事 | 规划开场、升级、转折、高潮和结尾，维持人物与剧情连续 |
| 带货及品牌广告 | 把商品放进有动机、有冲突、有反转的剧情，不再只是生硬介绍产品 |
| 图生视频、首尾帧 | 锁定人物身份、服装、场景和最终画面 |
| 多模态参考 | 分清图片、视频、音频各自控制人物、动作、运镜、声音还是节奏 |
| 视频续写 | 保留满意片段，只向前或向后延展新内容，减少明显接缝 |
| 二创、二改 | 局部换装、改色、移除物体、改变视角、移除BGM，其他内容保持不变 |
| 专业制作 | 绿幕合成、白模渲染、多格分镜、无缝转场和创意迁移 |
| 失败修复 | 诊断并修复变脸、换装、穿模、素材乱串、转场生硬和剧情漂移 |

## 核心优势

- **一句话也能开工**：不懂模式和术语，直接描述想法即可。
- **输出可以直接粘贴**：自动给出推荐设置、素材分工、完整提示词和避坑建议。
- **人物情绪更可执行**：把“难过、紧张、崩溃”等抽象情绪转换成眼神、呼吸、手势和身体动作。
- **参考素材不乱串**：明确每个素材能迁移什么、不能迁移什么。
- **能生成，也能修片**：整体正确时优先局部编辑，不必反复推倒重来。

## 使用示例

```text
使用 $seedance-25，生成一个30秒竖屏泡面带货短片：
深夜加班的女孩吃下泡面后出现温暖反转，人物情绪自然，商品特写诱人。
```

```text
使用 $seedance-25 修复 @视频1：
人物从第12秒开始变脸、衣服颜色改变，但场景、动作、运镜和声音全部保留。
```

```text
使用 $seedance-25：
@图片1控制人物身份和服装；@视频1只参考快速跟拍与结尾急停，
不要迁移原视频的人物、场景、声音和Logo。
```

## 第一步：安装 ChatGPT 桌面端

本技能推荐在包含 **Codex** 的 ChatGPT 桌面端中使用。

### Windows

1. 打开 [ChatGPT 官方下载页](https://openai.com/chatgpt/download/)，或在 Microsoft Store 搜索 **ChatGPT**。
2. 确认开发者为 **OpenAI**，完成安装。
3. 打开 ChatGPT，登录自己的 OpenAI 账号。
4. 进入 **Codex** 工作区；如果看不到 Codex，请检查账号套餐、地区或团队管理员设置。

Windows 官方要求为 Windows 10 17763.0 或更高版本。不要从不明网站下载所谓“破解版”。

### macOS

1. 从 [ChatGPT 官方下载页](https://openai.com/chatgpt/download/) 下载对应安装包。
2. 安装后登录账号，进入 ChatGPT 中的 **Codex** 工作区。

> 普通 ChatGPT 对话不一定具备本地技能目录能力；请在支持 Skills 的 Codex 任务中使用。

## 第二步：安装本技能

### 方法一：让 Codex 自动安装

把本仓库地址发给 Codex，并输入：

```text
请先检查风险，再安装这个技能：
https://github.com/zhangxiansheng-888/chuanzhang-seedance-25
```

### 方法二：手动安装

1. 下载本仓库 ZIP 并解压。
2. 找到完整目录 `skill/seedance-25`。
3. 将它复制到个人技能目录：

```text
Windows：C:\Users\你的用户名\.codex\skills\seedance-25
macOS：~/.codex/skills/seedance-25
```

4. 重新打开 ChatGPT/Codex，或新建一个 Codex 任务。
5. 输入下面这句话测试：

```text
使用 $seedance-25，把我的创意整理成一个30秒竖屏视频提示词。
```

## WordBuddy 是什么？

[WordBuddy AI](https://www.wordbuddy.ai/) 是一款独立的 AI 英语学习产品，主要提供词汇发现、口语和写作练习、AI 教练、间隔复习、词典与学习进度记录，可在 iOS、Android 和网页端使用。

它与本仓库的关系需要特别说明：

- WordBuddy 不是 Seedance 视频生成工具，也不是本技能的运行环境。
- 本技能主要运行在支持 Codex Skills 的 ChatGPT/Codex 中。
- 如果你所说的是另一个同名 WordBuddy 客户端，只有它明确支持 Codex `SKILL.md` 和个人技能目录时，才能按该客户端说明导入本技能。
- 不要把英语学习类 WordBuddy 与 ChatGPT/Codex、Seedance 2.5 混为同一个产品。
